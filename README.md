# 秦-Box

一款秦末历史人物聊天网页。玩家是咸阳魇胜师，兼通祝由术，可以与不同人物分别聊天；每个人物保留独立对话记忆。右侧「梦境共感」开关开启后，新产生的梦痕会进入共享记忆，供其他角色在后续聊天中引用；关闭后不向其他角色注入共享梦痕，但个人聊天记录仍保留。

刘邦和项羽需要全局信誉达到 100 解锁。与任一可联系人物成功对话后，全局信誉增加 2，每位人物的羁绊增加 4。信誉与所有聊天、物品、线索都保存在浏览器本机；可以导出 JSON 存档、重新导入或重启。

## Windows 启动

安装 Python 3.10 或更新版本后，双击 `启动秦匣.bat` 即可自动准备运行环境并打开网页。首次启动会安装依赖，需联网。也可以按以下步骤手动启动：

1. 安装 Python 3.10 或更新版本。
2. 在此文件夹打开 PowerShell，运行 `py -m venv .venv`。
3. 运行 `.venv\Scripts\Activate.ps1`。
4. 运行 `pip install -r requirements.txt`。
5. 打开 `config.py`，将 `DEEPSEEK_API_KEY` 设置为你的密钥。
6. 在私有 `config.py` 中设置 `QINBOX_ACTIVATION_CODE`，或通过环境变量配置服务器发放的虎符。此虎符不要提交到 GitHub。
7. 运行 `python app.py`。
8. 浏览器访问 http://127.0.0.1:5050 。

注册时填写虎符或自己的 DeepSeek Key。虎符与服务器保存的私有码匹配时使用服务器 Key；填写 `sk-...` 时使用玩家 Key。玩家 Key 只保留在当前页面内存中并经后端代理，不写入存档或数据库；刷新后可在游戏设置中重新填写。密钥只在本机服务端使用，不会下发到浏览器。若遇到执行策略限制，可直接运行 `.venv\Scripts\python.exe app.py`。

## 主要功能

- 九位历史人物的独立聊天窗口与人物档案。
- 催眠 On/Off 开关。开启时，系统把本局新产生的梦痕显式注入其他角色；关闭时保留私聊记忆但不共享。
- 全局信誉解锁刘邦、项羽。
- 历史线索手记：从对话关键词记录沙丘、指鹿为马、大泽乡、焚书等相关史实摘要。
- 背包与存档管理入口，存档在浏览器本地，可导入/导出/重启。
- 「发现」包含宫廷动态、兰台藏书室与军机沙盘：累计五次成功对话后，随机两位已解锁角色生成四句梦中交谈；全局记忆开启时，该段会写入共享梦痕。兰台收录上古至秦末史事。军机沙盘由蒙恬主管，可议事、修缮边塞、整训、赈济、筹粮、侦察、出击，并根据资源状态生成随机军报。「通译」提供文言繁体与白话互译、复制粘贴，以及李斯主持的书同文积分玩法；答对文言常识题得 2 分，可与李斯研读《谏逐客书》。

## 史实与演绎

故事把不同年代的人物通过魇胜师梦境联系起来，属于明确标记的戏剧设定。历史线索依据《史记》相关篇章整理；“传国玉玺”与“楚人一炬”等内容会标明传说、文学表达与史书记载之间的区别。详细脉络见 `HISTORY.md`。

## 目录

- `app.py`：本机 Flask 服务及 DeepSeek 请求。
- `config.py`：本机 API 密钥设置（已加入 git 忽略）。
- `prompts/`：共享规则与九位角色设定。
- `templates/`：网页入口。
- `static/`：前端样式、交互、宫廷/兰台页面和角色图片。
- `images/`：原始头像资源及角色拼图。
